# Binja Diff View v0.1.10

This release fixes a crash while preparing the selected-function diff overlay.
Operand classification now keeps its BinaryView reference alive until section
lookups finish.

## Downloads

- `binja_diff_view-v0.1.10-macos-arm64-bn6.1.11209-dev.tar.gz` contains the
  signed native plugin, the private Rust engine, build metadata, and licenses.
- `binja_diff_view-v0.1.10-source.tar.gz` contains the source at the release tag.
- `SHA256SUMS.txt` contains the checksums of both archives.

The Apple Silicon package targets Binary Ninja **6.1.11209-dev** with
**core ABI 195**, **UI ABI 22**, and **Qt 6.11.1**. The plugin's macOS
deployment target is 13.0. For Binary Ninja 6.1.11164-dev (core ABI 194),
use the [v0.1.9 package](https://github.com/meerkatone/binja_diff_view/releases/tag/v0.1.9).

## Install

Verify the download with `shasum -a 256 -c SHA256SUMS.txt --ignore-missing`.
Quit Binary Ninja and extract the native archive. From the extracted directory,
copy the plugin and its private engine together.

```sh
ditto plugins "$HOME/Library/Application Support/Binary Ninja/plugins"
```

Restart Binary Ninja, open two analyzed binaries, then select **Plugins →
Binja Diff View → Binja Diff: Open Workspace**.

## Validation

- Built against Binary Ninja API tag `dev/6.1.11209` and Qt 6.11.1.
- All 13 CTest unit targets and Vector 35's metadata checker passed. Both ARM64
  libraries passed strict signature verification.
- A clean-profile GUI check on Binary Ninja Personal 6.1.11209-dev compared
  two x86-64 Mach-O fixtures and rendered one changed disassembly block.
  The original crash inputs remain unverified.
