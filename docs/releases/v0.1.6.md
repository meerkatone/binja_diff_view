# Binja Diff View v0.1.6

This is a compatibility rebuild for Binary Ninja **6.1.11108 development** on
**macOS Apple Silicon**. Matching and UI implementation are unchanged from
v0.1.5. The plugin metadata and bundled engine version are now 0.1.6; the
minimum Binary Ninja build is 11108. Third-party Rust dependencies are unchanged.

## Downloads

- `binja_diff_view-v0.1.6-macos-arm64-bn6.1.11108-dev.tar.gz`: native plugin,
  private Rust engine, installation instructions, build metadata, and licenses.
- `binja_diff_view-v0.1.6-source.tar.gz`: source at the release commit.
- `SHA256SUMS.txt`: SHA-256 checksums for both archives.

The native package requires **core ABI 192**, **UI ABI 21**, and **Qt 6.11.1**.
Other builds may require rebuilding. The
[v0.1.5 package](https://github.com/meerkatone/binja_diff_view/releases/tag/v0.1.5)
remains available for build 11107; builds using UI ABI 20 need the
[v0.1.3 package](https://github.com/meerkatone/binja_diff_view/releases/tag/v0.1.3)
or a source build.

## Install

Check the downloaded archives with `shasum -a 256 -c SHA256SUMS.txt --ignore-missing`.
Quit Binary Ninja, extract the native archive, then run from its directory:

```sh
ditto plugins "$HOME/Library/Application Support/Binary Ninja/plugins"
```

Preserve the hidden `plugins/.binja_diff_view` directory. Restart Binary Ninja,
open two analyzed binaries, and select **Plugins → Binja Diff View →
Binja Diff: Open Workspace**.

- All 12 CTest unit targets passed, including 118 Rust regressions.
- Engine Clippy passed with warnings denied.

  expected for the empty `longdescription` field.

  matches, no wrong matches, one missed match offered as a review hint, and
  symmetric forward/reverse results.

  Binary Ninja integration tests. Unit tests and library loading do not
