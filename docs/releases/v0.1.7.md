# Binja Diff View v0.1.7

This release fixes corpus drill-downs on freshly loaded views. It is built for
Binary Ninja **6.1.11124 development** on **macOS Apple Silicon**. The
plugin metadata and bundled engine version are now 0.1.7, and the minimum
Binary Ninja build is 11124. Third-party Rust dependencies are unchanged.

## Changes

Opening a corpus drill-down on freshly loaded views could fail with "The
corpus pair changed while its drill-down workspace was opening". Extracting a
view regenerates IL, which can make Binary Ninja create or reanalyse
functions. Those notifications invalidated the corpus snapshot while the
drill-down was registering its panes.

- Extraction now absorbs the function changes that its own IL requests cause.
  It runs analysis to completion, then re-extracts only the reported functions
  and their callees' caller lists. It repeats until a round reports nothing.
- Views whose analysis changed after loading no longer use the disk cache.
- Function add, update and remove notifications that arrive outside
  extraction are batched and re-extracted on a worker. A view is invalidated
  only when a function's extraction differs from its recorded digest, or no
  digest exists.

## Install

Check the downloaded archives with
`shasum -a 256 -c SHA256SUMS.txt --ignore-missing`. Quit Binary Ninja,
extract the native archive, then run this from its directory:

```sh
ditto plugins "$HOME/Library/Application Support/Binary Ninja/plugins"
```

Keep the hidden `plugins/.binja_diff_view` directory. Restart Binary Ninja,
open two analyzed binaries, and select **Plugins → Binja Diff View → Binja
Diff: Open Workspace**.

## Validation

- **Build.** The release C++ plugin was built against API tag
  `dev/6.1.11124`, the same upstream commit as `dev/6.1.11118`. The bundled
  Rust engine was built with the locked dependencies. The configure-time ABI
  probe passed against the installed 6.1.11124 core.
- **Tests.** All 13 CTest unit targets passed, including the new
  extraction-settling test. The engine's 118 Rust tests passed, and Clippy
  passed with warnings denied.
- **Linking.** The plugin's 435 imports from the Binary Ninja core and UI
  libraries and from QtCore, QtGui, QtWidgets and QtConcurrent all resolve
  against the libraries in the installed 6.1.11124 application. The bundled
  Qt is 6.11.1.
- **Signatures.** Both packaged libraries are ad-hoc signed, and their
  signatures verify.
- **Metadata.** `plugin.json` parses and contains every field in the
  metadata template. Vector 35's metadata checker was not run for this
  release.
- **Not run.** No GUI installation or smoke test was done for this package,
  and no licensed integration tests were run. Unit tests and the import check
  do not establish Graph/Linear rendering or workspace behaviour.

The binary archive's `BUILD.json` records the source commit and the checksum
of each library.
