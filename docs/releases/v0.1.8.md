# Binja Diff View v0.1.8

This release corrects how vulnerable and patched functions are matched and
classified. It is built for Binary Ninja **6.1.11124 development** on **macOS
Apple Silicon**, the same build as v0.1.7. The plugin metadata and bundled
engine version are now 0.1.8. Third-party Rust dependencies are unchanged.

Match schema 26 and extraction schema 13 replace earlier cached results, so
the first comparison after upgrading re-extracts both views.

## Changes

An audit of the matcher against vulnerable → fixed pairs found real patches
reported as unchanged, patched functions left unmatched, and false positives.

- **Literal operands are no longer treated as addresses.** On x86, Binary
  Ninja types every full-width immediate as a possible address, so
  `cmp rdx, 0x100` → `cmp rdx, 0xff` compared equal. On every architecture, a
  stack or structure displacement such as `[x8, #0x8]` was accepted as an
  image-relative address and normalized away. An operand is now an address
  only with evidence: the instruction references it, it is a block start, or
  it is an absolute value of at least 0x10000 inside a section. A PE
  image-relative offset in an indexed operand also counts. Changed bounds,
  structure fields and stack slots are now `Changed`.
- **Heavily patched functions are matched.** A fix that adds a bounds-check
  block can drop body similarity below every threshold. Such a function was
  reported as one removed and one added function. A pair is now accepted as a
  CallGraph match when it is the only unmatched neighbor of at least two
  agreeing matched functions on both sides, with no contradiction. Its
  confidence is capped at 50%.
- **Calls are compared by callee identity.** In stripped builds, a call
  redirected from one matched `sub_` function to another compared equal. It
  is now `Changed`. A call whose only difference is the callee's name, as
  when one build is stripped, is now `Cosmetic` rather than `Changed`.
- **Mach-O `_name` matches `name`.** Symbol-table names keep a leading
  underscore that debug names drop. One leading underscore is now ignored for
  name matching, unless the binary defines both spellings.
- **Security triage.** Short keywords no longer match inside other words:
  `read` in `pthread`, `uid` in `cpuid`, `rsa` in `traversal`. A guard added
  to a function that already calls a memory routine is recorded as context.

Structure layout changes now count as `Changed` because the machine code
differs. Curl 8.4.0 enlarged its configuration structures, so 165 functions
that 0.1.7 reported as `Cosmetic` are now `Changed` with only displacement
differences. Use similarity and security state to rank them below
control-flow changes.

## Install

Check the downloaded archives with
`shasum -a 256 -c SHA256SUMS.txt --ignore-missing`. Quit Binary Ninja,
extract the native archive, then run this from its directory:

```sh
ditto plugins "$HOME/Library/Application Support/Binary Ninja/plugins"
```

Keep the hidden `plugins/.binja_diff_view` directory. Restart Binary Ninja,
open two analyzed binaries, and select **Plugins → Binja Diff View → Binja
Diff: Open Workspace**.

## Validation

- **Build.** The C++ plugin was built against API tag `dev/6.1.11124`
  (commit `23dfe06e`, also tagged `dev/6.1.11118`). The bundled Rust engine
  was built with the locked dependencies.
- **Tests.** All 13 CTest unit targets passed. The engine's 124 Rust tests
  passed, and Clippy passed with warnings denied. The memcpy accuracy fixture
  has five of five pairs correct, no wrong pair, in both directions.
- **GUI.** The packaged plugin library was installed in Binary Ninja
  6.1.11124-dev Personal and used for Open Workspace on curl 8.3.0 → 8.4.0
  and sshd 9.7p1 → sshd-session 9.8p1. The curl CVE-2023-38545 fix,
  `_do_SOCKS5`, is `Changed`. The sshd workspace reported 7,172 matches,
  43 A-only and 7 B-only functions. The engine in that test differed from the
  packaged engine only in its version string.
- **Signatures.** Both packaged libraries are ad-hoc signed, and their
  signatures verify.
- **Not run.** Vector 35's metadata checker and the licensed integration
  tests were not run.

The binary archive's `BUILD.json` records the source commit and the checksum
of each library.
