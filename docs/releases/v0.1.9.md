# Binja Diff View v0.1.9

This release adds a macOS Apple Silicon build for Binary Ninja **6.1.11164-dev**
and reduces the work required to maintain the on-disk cache. The cache sorts
artifacts by eviction priority only after its byte or file count limit is
exceeded. Existing match and extraction caches remain compatible.

## Downloads

- `binja_diff_view-v0.1.9-macos-arm64-bn6.1.11164-dev.tar.gz` contains the
  signed native plugin, the private Rust engine, installation instructions,
  build metadata, and licenses.
- `binja_diff_view-v0.1.9-source.tar.gz` contains the source at the release tag.
- `SHA256SUMS.txt` contains the checksums of both archives.

The native package uses **core ABI 194**, **UI ABI 22**, and **Qt 6.11.1**.
Its macOS deployment target is 13.0. For Binary Ninja 6.1.11124-dev (core ABI
193), use the [v0.1.8 package](https://github.com/meerkatone/binja_diff_view/releases/tag/v0.1.8).

## Install

Verify the download with `shasum -a 256 -c SHA256SUMS.txt --ignore-missing`.
Quit Binary Ninja and extract the native archive. From the extracted directory,
copy the plugin and its private engine together:

```sh
ditto plugins "$HOME/Library/Application Support/Binary Ninja/plugins"
```

Restart Binary Ninja, open two analyzed binaries, then select **Plugins →
Binja Diff View → Binja Diff: Open Workspace**.

## Validation

- Built against Binary Ninja API tag `dev/6.1.11164` and Qt 6.11.1.
- All 13 CTest unit targets passed, including 124 Rust tests. Clippy passed
  with warnings denied. Vector 35's metadata checker passed.
- Both ARM64 libraries passed strict signature verification.
- A clean-profile GUI smoke test on Binary Ninja Personal 6.1.11164-dev
  confirmed the private engine loaded and Open Workspace matched two
  functions across two small Mach-O fixtures on macOS 27.2.1.
